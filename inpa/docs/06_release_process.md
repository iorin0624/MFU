# INPA リリース運用

INPAの本番変更では、コード、`inpa/VERSION`、公開用アップデート情報を同じリリースで更新します。

## バージョン

- メジャー変更: `x+1.0.0`
- 機能追加: `x.y+1.0`
- 修正・表示調整: `x.y.z+1`
- 複数種類を同時に公開する場合は最も大きい変更区分を採用します。
- 先頭ゼロを付けず、公開済みより大きいバージョンだけを公開します。

## リリース手順

1. MFU管理の「アップデート」で次のバージョンを選び、タイトルと利用者向け変更内容を下書きにします。
2. コードとテストを完了し、`inpa/VERSION`を同じバージョンへ更新します。
3. DBマイグレーション、アプリ配置、動作確認を行います。
4. アップデート情報を公開します。
5. 公開画面のフッター、履歴、初回アクセスモーダルが同じバージョンであることを確認します。

公開済み情報は変更しません。訂正が必要な場合は、修正バージョンを新規作成して公開します。
