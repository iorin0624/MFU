# 画像ビュアーの服装分類（第1段階）

大分類は `ロリータ系`、`地雷系`、`私服系` の3択。1画像につき大分類を1つ選び、その下に中分類を複数、中分類ごとに小分類を複数保存する。ディズニーなどのテーマは大分類を増やさず、中・小分類で表現できる。未分類の画像も許可する。

画像ビュアーで画像の「プロパティ」を開くと、分類タグを手動で編集できる。分類は画像の SHA-256 をキーに `/mnt/mfu/data/image_viewer_style_tags.sqlite3` に保存するため、ファイル名やフォルダーを変更しても維持される。同一内容の複製は同じ分類を共有する。元画像は変更しない。

この段階では自動分類・検索フィルターは未実装。手動タグは、後続の分類モデルを評価する正解データとして利用できるが、人物の同一性や年齢は推定しない。

## CPU/GPU比較

`tools/image_style_benchmark.py` は同一の入力・モデルを CPU と GPU で推論し、コンパイル時間、推論時間の中央値・95パーセンタイル、出力差を JSON で返す。

```bash
python tools/image_style_benchmark.py --warmup 5 --runs 20
python tools/image_style_benchmark.py --model /path/to/image-encoder.onnx --warmup 5 --runs 20
```

モデル指定なしは小さな合成ネットワークによる「計算デバイス認識」の確認だけで、実際の服装分類モデルの速度・精度を示さない。OpenVINOの推論先として GPU が認識されない場合は `unavailable` と報告し、CPU値をGPU比較結果として扱わない。後続段階で採用する画像エンコーダーを `--model` に指定してから最終的な実測を行う。
