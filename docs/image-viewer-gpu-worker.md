# Media Hub GPU服装分類

画像ビュアーの画像プロパティから「GPUで候補を作成」を押すか、一覧で
写真を複数選択して「選択画像をGPU分類」を押すと、MFUサーバーは
所有ユーザー別の永続ジョブを登録します。ログイン済みのMedia Hubだけがジョブを
取得でき、768px以内に縮小・EXIFを除去した画像だけを受け取ります。
WebSocketイベントで即時に起床し、イベントを失った場合も30秒ごとに再確認します。
結果は分類候補として保管し、既存の確定タグを自動変更しません。
一括依頼は30枚ずつ投入し、一覧下部に完了・失敗件数を表示します。

## Windows側の準備

RTX 4060を接続した端末で `tools/mfu_media_hub/install_gpu.ps1` を実行します。
GPU用Python環境は `%LOCALAPPDATA%\MFU\MediaHubGPU` に置き、PyInstallerの
Qtアプリ本体にはPyTorchを混ぜません。初回分類時はOpenAI CLIPの公開モデル
をダウンロードします。画像データはモデル配布元へ送信しません。

ビルドは `tools/mfu_media_hub/build.ps1` です。`gpu_classifier.py` を配布物に
同梱します。Media Hubのトークンは既存のDPAPI管理を使います。

## 判定上の注意

大分類はロリータ系・地雷系・私服系の3つです。ディズニー衣装は私服系の
中分類候補です。汎用CLIPモデルの相対スコアは確率校正された信頼度ではなく、
撮影場所・背景・衣装に影響されます。候補を編集欄へ反映しただけでは確定せず、
ユーザーが確認して「分類タグを保存」を押したときだけ確定します。
